# Partition: root — Documentation Health

La navigazione segue `docs/INDEX.md`, `docs/adr/README.md` e le lead del run. I documenti sono dichiarazioni da confrontare col sorgente, non autorità sostitutive. Gli ID `DQ-*` identificano questioni documentali; non aggiungono nuove istanze ai rischi `XQ-*` di `05-risks.md`. **verified** indica riscontro nel codice o controllo locale osservato, **documented** una dichiarazione del documento, **disputed** una divergenza esplicita, **unverified** una promessa che il controllo statico non può dimostrare.

**[verified, strumenti]** `doc_review.py` 4.0.2 è stato usato via API, senza output su file, fix o backup: `scan`, `validate_links(fix=False)` e `validate_markers` su `docs/` e `processes/`. Il primo scope contiene 31 Markdown, il secondo 1; nessun errore di lettura, link Markdown locale rotto o marker `[VERIFIED: ...]`/`[VALIDATED: ...]`. Gli stessi pattern/API hanno controllato `README.md`, `AGENTS.md` e `CLAUDE.md`: un link locale nel README, valido, nessun marker. Il controllo non valida URL remoti, ancore di sezione, percorsi racchiusi soltanto in backtick o correttezza semantica delle citazioni. Gli zero marker non sono zero affermazioni tecniche, né una misura di qualità.
