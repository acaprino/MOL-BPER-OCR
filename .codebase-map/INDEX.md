# poc-data-extraction - Codebase Guide

A Python proof-of-concept that extracts structured fields from Italian BPER banking screenshots with a multi-pass Vision-LLM pipeline (OpenAI / Gemini via LangChain), then scores each field against a ground-truth CSV and reports per-field accuracy and per-call cost. One extraction engine, three front-ends: CLI batch, Tkinter desktop GUI, and a PyQt6 live-capture edge-agent.
