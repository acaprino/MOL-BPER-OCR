# poc-data-extraction - Codebase Guide

A Python proof of concept that uses Vision Language Models (OpenAI GPT-4o, Google Gemini) to extract 45 structured fields from Italian BPER banking screenshots. Ships as three interfaces on top of one shared `extraction/` pipeline: a CLI batch runner, a Tkinter desktop GUI, and a PyQt6 edge-agent with live screen capture.

## Key Facts

- **Language:** Python 3.8+ required; 3.13 observed in compiled bytecode
- **Core framework:** LangChain (`langchain-core`, `langchain-openai`, `langchain-google-genai`)
- **LLM providers:** OpenAI (GPT-4o, 4o-mini, o1) and Google Gemini (1.5/2.0/3.x Flash and Pro)
- **UI toolkits:** Tkinter (`gui_app.py`) and PyQt6 + qt-material (`edge-agent/`)
- **ML framework:** PyTorch + torchvision for DINOv2 ViT-S/14 page classification (optional, degrades to LLM-only routing)
- **Database:** None. In-memory dicts, CSV ground truth, JSON output files
- **Entry points:** `main.py` (CLI and `--gui` shim), `gui_app.py` (Tkinter), `edge-agent/edge_agent.py` (PyQt6 direct)
- **Status:** Proof of concept. No tests, no CI, no Docker, no linter config. `develop` is the working branch, `master` is main.
